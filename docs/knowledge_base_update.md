# Инструкция по обновлению базы знаний и переиндексации

## Что входит в базу знаний

```
data/knowledge/
├── lectures/     # лекции (.md)
├── methodics/    # методички (.md)
└── faq/          # FAQ (.md)
```

Каждый файл должен содержать заголовок с метаданными:

```markdown
# Название материала

**Модуль:** 2. Функции и модули  
**Тема:** Функции  
**Тип:** Лекция  
**Уровень:** beginner  

## Содержание
...
```

Допустимые значения **Тип**: `Лекция`, `Методичка`, `FAQ`  
Допустимые значения **Уровень**: `beginner`, `advanced`

## Как добавить новый материал

1. Создайте `.md` файл в нужной папке.
2. Заполните метаданные в шапке (модуль, тема, тип, уровень).
3. Добавьте содержание; разделяйте разделы заголовками `##`.
4. Переиндексируйте базу (см. ниже).

## Как обновить LMS-данные

- Расписание: `data/lms/schedule.json`
- Задания: `data/lms/assignments.csv`

Переиндексация Chroma для LMS **не нужна** — данные читаются напрямую при каждом запросе.

## Как обновить few-shot примеры

Отредактируйте `data/few_shot/examples.json`:

- блок `correct` — эталонные ответы;
- блок `incorrect` — антипаттерны с полем `why_incorrect`.

Перезапустите Streamlit (промпт подхватит файл при следующем запросе).

## Переиндексация

### Через UI

1. Откройте приложение Streamlit.
2. Раздел **База знаний**.
3. Нажмите **Переиндексировать базу знаний**.

### Через CLI

```bash
# из корня проекта, с активированным venv
python scripts/reindex.py
```

Скрипт:

1. Удаляет старую `./chroma_db`
2. Читает все `.md` из `data/knowledge`
3. Делит на чанки, строит эмбеддинги OpenAI
4. Сохраняет коллекцию Chroma

Требуется переменная `OPENAI_API_KEY` в `.env`.

## Проверка после обновления

1. Задайте в чате вопрос по новому материалу.
2. Убедитесь, что в «Источниках» появился новый файл.
3. При фильтре по модулю/типу — проверьте, что лишние документы не подтягиваются.

## Рекомендации по качеству чанков

- Одна тема — один файл (или чёткие `##` разделы).
- Избегайте огромных таблиц без пояснений.
- Для FAQ держите пары Q/A компактными.
- После крупных правок всегда делайте полную переиндексацию.
